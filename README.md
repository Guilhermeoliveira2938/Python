## ▶️ Como rodar

1. Instale o [Python 3](https://www.python.org/downloads/)
2. Clone o repositório e entre na pasta:
   ```bash
   git clone https://github.com/Guilhermeoliveira2938/Python.git
   cd Python
   ```
3. Rode o script que quiser, por exemplo:
   ```bash
   python organizador_arquivos/organizador.py
   ```
